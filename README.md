# Умные указатели

Учебная работа по управлению памятью в C++. Здесь написаны `UnqPtr<T>` для единоличного владения и `ShrdPtr<T>` для совместного. `MemorySpan<T>` хранит элементы в самописном `DynamicArray<T>`, а `MsPtr<T>` позволяет обращаться к ним и проверяет границы.

Код указателей разложен по заголовкам в `include/`: `UnqPtr.hpp`, `ShrdPtr.hpp` и `MemorySpan.hpp`. Если нужны все классы сразу, достаточно подключить `smart_pointers.hpp`. Контейнер и связанные с ним типы исключений взяты из предыдущих лабораторных и лежат рядом.

## Запуск

Нужны C++-компилятор с поддержкой C++20 и `make`.

```bash
make           # собрать программу
make run       # открыть меню с демонстрациями
make test      # выполнить функциональные проверки
make sanitize  # прогнать проверки под AddressSanitizer и UBSan
make benchmark # сравнить время и оценку памяти
make graph     # построить график по benchmark.csv
make clean     # удалить сборочные файлы
```

Первый запуск `make` создаёт каталог `build/`. `make clean` удаляет его; Git игнорирует сборочные каталоги и файл `HW1_sources.txt`.

В тестах проверяются перемещение и освобождение владения, счётчик `ShrdPtr`, преобразование между базовым и производным типами, удаление объекта при множественном наследовании, а также граничные случаи `MemorySpan` и `MsPtr`.

На Linux `make sanitize` включает проверку утечек. В поставляемом AppleClang на macOS LeakSanitizer недоступен, поэтому там проверяются ошибки доступа к памяти и неопределённое поведение, но не утечки.

## Бенчмарк

Замеры сравнивают обычные указатели, `UnqPtr` и `ShrdPtr` на наборах до миллиона объектов. Результаты записываются в `benchmark.csv`; скрипт `plot_benchmark.py` строит график. Показатель памяти — расчёт по размерам объектов и структур владения, а не замер фактического потребления аллокатора.

Чтобы собрать тексты файлов проекта в один документ для просмотра, выполни `make sources-txt`. Результат появится в `HW1_sources.txt`.
